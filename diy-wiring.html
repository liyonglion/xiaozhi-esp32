DIY 硬件装配 · ESP32-S3

面包板小布 · 装配图

按你买的套装画的俯视装配图：两块 400 孔面包板背胶拼接成一块长板， DevKitC-1 居中跨槽插，两块 INMP441 在左、MAX98357A 在右、喇叭接功放端子。 共 19 根公对公杜邦线拱线连接；两个麦的级联不占额外线——靠 「同色两根线插开发板同一引脚列的不同孔」实现（面包板每一列 5 孔内部连通）。 功放的 SD / GAIN 两脚不能悬空（见第④步与避坑节），另有一颗 470µF 电容并联在 VIN/GND 上。 屏幕为可选件（表情脸 25 号票，暂缓购买）——图默认不显示，点「⑤ 屏幕」按钮可预览接法。

第①步 电源与地（3 红 + 3 黑）

  1. 红：麦① VDD → 开发板「3V3」列任一空孔
  2. 红：麦② VDD → 3V3 列另一个空孔
  3. 红：功放 VIN → 开发板下排「5V」列
  4. 黑：麦① GND → 上排「GND」列空孔
  5. 黑：麦② GND → 上排 GND 列另一空孔
  6. 黑：功放 GND → 下排 GND 列空孔

口诀：每一列 5 孔内部连通，插同列哪个空孔都等价；但一个孔只插一根线。插完自查——红线只碰 3V3 / 5V，黑线只碰 GND。

第②步 麦克风①（蓝 / 绿 / 黄 / 黑 各 1）

  1. 蓝：SCK → 「GPIO4」列的上孔（记为孔 A）
  2. 绿：WS → 「GPIO5」列的上孔（孔 A）
  3. 黄：SD → 「GPIO6」列的上孔（孔 A）
  4. 黑：L/R → 上排「GND」列空孔 ——这根决定它是左声道

这步结束后 GPIO4 / 5 / 6 三列各自的上孔已占用，下步的麦②要插同列的下一个空孔。

第③步 麦克风②（蓝 / 绿 / 黄 / 红 各 1）——级联在这步自动完成

  1. 蓝：SCK → 「GPIO4」列的下一个空孔（孔 B）
  2. 绿：WS → 「GPIO5」列的孔 B
  3. 黄：SD → 「GPIO6」列的孔 B
  4. 红：L/R → 「3V3」列空孔 ——这根决定它是右声道

两块麦的同名脚落在同一列的不同孔 = 并联 = 级联。两根 L/R 一黑一红（一个接 GND 一个接 3V3）是整套接线里最容易漏/接反的地方。

第④步 功放与喇叭（5 根线 + 电容 + 喇叭）

  1. 蓝：BCLK → 下排「GPIO7」列
  2. 绿：LRC → 下排「GPIO15」列
  3. 黄：DIN → 下排「GPIO16」列
  4. 红：SD → 上排「3V3」列空孔 ——必须接！兼容模块无分压电阻，悬空 = 关断，完全无声；接 GND = 永久静音
  5. 红：GAIN → 下排「5V」列空孔 ——固定 6dB 增益。悬空 9dB 音量一大就高音破音（实测踩坑）；接 GND 会升到 12dB 更糟
  6. 电容：470µF/16V 直接插面包板，长脚(+) 插 VIN(5V) 列空孔、短脚(−，壳上条纹侧) 插 GND 列空孔——并联跨接，不占杜邦线，接反会鼓包
  7. 喇叭：自带线剪掉 1.25 端子头、剥出 3mm 铜线，两根拧进功放的绿色端子（不占杜邦线）

GAIN 是上电时采样的——改接后必须断电重启才生效。这步做完接上 USB 就能烧固件听声了（屏幕不亮是正常的，驱动在 25 号票）。

第⑤步 屏幕（可选——暂不买屏就整步跳过）

  1. 蓝：SCL → 「GPIO12」列
  2. 黄：SDA → 「GPIO13」列
  3. 紫：RES → 「GPIO9」列
  4. 紫：DC → 「GPIO11」列
  5. 紫：CS → 「GPIO10」列
  6. 紫：BLK → 「GPIO14」列 ——背光控制，将来「静默熄屏」靠它，别图省事接 3V3

没有紫线就用别的颜色代替，插对列就行——颜色只是给人看的，电只认孔位。

电源 3V3 / 5V 地 GND 位时钟 SCK / BCLK / SCL 声道时钟 WS / LRC 数据 SD / DIN / SDA 屏幕控制 RES / DC / CS / BLK

线色即杜邦线色标，照着插即可。图是俯视图：杜邦线拱在器件上方的空中，交叉不相连。

§1面包板三件事（看懂就能插对）

列连通中间槽两侧，每一竖列 5 孔内部连通 所以「开发板 GPIO4 那一列」= 5 个等效的 GPIO4 孔。两个麦的 SCK 线（蓝×2）就分别插这一列的两个孔——不用挤同一个孔，效果=并联。这就是级联的全部秘密。
插法器件排针跨中间槽 / 单排模块插一行 DevKitC-1 双排针正好骑在中间槽两侧压进去；两块 INMP441 和 MAX98357A 的单排针各插在上半区的一行里。排针插不进时检查是不是顶到了槽沿。
跨缝线可以跨拼接缝，孔列不行 两块 400 孔拼接后，杜邦线（空中拱线）随便跨；但每列孔的导通只在各自板内。本图已把每个信号的孔安排在同一列，照图插就没有跨列问题。电源轨全程不用，留空。

§3插装顺序建议

步做什么要点
1两块面包板背胶拼接对齐边沿拼成一块长板；缝隙越小列孔越正

§4避坑

  • 排针没插到底 = 最高发故障：每个器件压入后目视检查排针根部没悬空；上电没反应先按一遍所有器件。
  • 任何器件都不骑拼接缝：接缝处中间槽断开、两侧孔列常错半孔（背胶手拼对不齐 2.54 栅格），双排针/单排针骑缝都插不进或接触不良。开发板、每个模块整段落在一块板内；两块 INMP441 必须同一块板（级联同列靠板内导通）；只有杜邦线可以随便跨缝。嫌拼麻烦也可两板分开放、全靠杜邦线跨板。
  • 别用这些 GPIO：GPIO0（BOOT 键留着长按）、GPIO19/20（USB）、GPIO26–32（板载 Flash）、GPIO35–37（八线 PSRAM 占用）。本图选的 4/5/6/7/9/10/11/12/13/14/15/16 全部避开；若换引脚，固件里的宏要跟着改。
  • 面包板效果预期：麦克风间距和走线不受控，端到端能跑通，AEC/唤醒会比 BOX-3 的结构化麦阵打折。固件侧 ADC_GAIN_DB、VAD_SILENCE_END_MS、BARGEIN_FRAMES 三个旋钮届时按 README 验收清单调。
  • 供电容量：满音量 + WiFi 瞬时电流约 1A——电脑插 USB 3.0 口（900mA+），黑色 USB 2.0 口大音量时可能欠压重启。
  • 功放三个脚的实测结论（2026-10-17）：SD 悬空 = 无声（兼容模块无分压，关断）→ 必须接 3V3；GAIN 悬空 = 9dB，高音破音 → 接 VIN(5V 列) 固定 6dB（接 GND 会到 12dB，更糟）；再并联 470µF/16V 电容跨 VIN/GND 作电源储备——长脚(+) 朝 VIN、短脚(−，壳上条纹侧) 朝 GND，接反会发热鼓包。GAIN 上电采样，改接后断电重启才生效。
  • 全程无需烙铁：喇叭线用剪刀剥线即可。

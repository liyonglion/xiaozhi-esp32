小智桌面三屏原型

画布 320×480（3.5" ST7796 1:1）· 三屏：天气 / 学习进度 / 待办，实机为 lv_tileview 左右滑翻页
硬约束：仅圆角矩形 / 文字 / lv_bar / 复选框，无渐变阴影；字号 ≥14px，主信息 20–74px；状态栏留 WiFi + 时钟
切换：底部浮条或键盘 ← / →；P3 任务行可直接点选看勾选态 · 天气为 Open-Meteo 实测样例（南京·江宁·禄口）

A · 儿童大字卡

大数字、大图标、白卡片，孩子隔一米也能看清；三屏都用同一套「标题—大数字—卡片」节奏。

LVGL 代价：emoji 图标需在固件打包图标资源；浅底整屏刷新稍慢于深底。

B · 深色仪表盘

单层深色面板、细分割线、数字分级；信息密度最高，家长扫一眼全有。

LVGL 代价：最低——全部为原生控件（label / lv_bar / 线条），深底还省 SPI 刷新时间。

C · 小黑板

一块木框黑板贴在墙上：粉笔白/黄/粉三色 + 虚线分隔，学习场景代入感最强。

LVGL 代价：木框 = 带边框矩形，粉笔感全靠配色与虚线（line dash），可实现；手写体固件端退回 noto，靠字号与颜色保留气质。

实机翻页：左右滑动切换三屏（lv_tileview 局部刷新，无整页转场动画）
